# TMB_Recomp

Static recompilation of **Twisted Metal: Black** (PlayStation 2, PAL release
`SCES-50360`) to a native executable, built on
[PS2Recomp](https://github.com/boubou666/PS2Recomp) (fork of
[ran-j/PS2Recomp](https://github.com/ran-j/PS2Recomp)).

This repository does **not** contain any game data. You need your own dump of
the PAL disc (`Twisted Metal - Black (Europe) (En,Fr,De,Es,It)`). The game ELF,
the extracted disc, and the generated C++ are all git-ignored.

## Status

Early bring-up. The full ELF (3572 functions, symbols intact) recompiles cleanly
and links into `ps2EntryRunner`. Whether it boots to the title screen is being
worked on; see the issues for current blockers.

## Layout

| Path | What |
| --- | --- |
| `PS2Recomp/` | Submodule: the recompiler, analyzer and runtime |
| `config/tmb_sces50360.toml` | Recompiler config generated by `ps2_analyzer` for this ELF (hand-tunable) |
| `overrides/` | Game-specific runtime overrides, compiled into the runner |
| `scripts/` | Helper scripts for every step below |
| `game/` | Extracted disc (ignored) |
| `generated/` | Output of `ps2_recomp` (ignored) |
| `build/` | CMake build trees (ignored) |

## Requirements

* Linux (tested on Arch), CMake 3.21+, Ninja, a C++20 compiler (GCC or Clang)
* FFmpeg development libraries (`libavcodec`, `libavformat`, `libavutil`, `libswresample`, `libswscale`)
* X11/Wayland + OpenGL development headers for raylib
* `bsdtar` (libarchive) to extract the ISO

## Build

```bash
git clone --recurse-submodules https://github.com/boubou666/TMB_Recomp.git
cd TMB_Recomp

scripts/extract_iso.sh "/path/to/Twisted Metal - Black (Europe) (En,Fr,De,Es,It).iso"
scripts/build_tools.sh      # builds ps2_recomp + ps2_analyzer into build/tools
scripts/recomp.sh           # ELF + config -> generated/
scripts/build_runtime.sh    # links generated code with ps2xRuntime -> build/game
scripts/run.sh              # runs ps2EntryRunner on game/SCES_503.60
```

`scripts/analyze.sh` regenerates the TOML from scratch with the analyzer. Only
run it when you want to reset the config, since it discards manual edits.

## How it works

1. `ps2_analyzer` reads the ELF symbol table (this build is not stripped), finds
   SCE SDK functions that have runtime handlers, and writes the stub/entry-point
   lists into the TOML.
2. `ps2_recomp` translates every MIPS R5900 function to C++ (one file per
   function) and emits `register_functions.cpp` with the address table.
3. The top-level `CMakeLists.txt` builds `PS2Recomp/ps2xRuntime`, swaps its
   placeholder function table for the generated one, and links everything into
   `ps2EntryRunner`.
4. At run time, `cdrom0:` is mounted on the directory containing the ELF, so
   the extracted `game/` folder acts as the disc.

## Disc facts

| | |
| --- | --- |
| Boot ELF | `SCES_503.60`, entry `0x100008` |
| Video mode | PAL |
| IOP modules | `MOD/*.IRX` (989SND, LGDEV, LIBSD, MCMAN, MCSERV, MTAPMAN, PADMAN, SIO2MAN, SNDBGET, USB*) |
| IOP image | `IOPRP213.IMG` |
